# ブラウザ完結試作版

ChulipVideo v0.3.0のメイン編集画面を、PCのWebブラウザで利用する試作版です。動画・操作履歴は端末内で処理し、サーバーへアップロードしません。録画画面とWindowsの窓調整は対象外です。

## 起動

```powershell
cd ChulipVideo-Web
npm ci
npm run web:dev
```

表示された `http://127.0.0.1:1421` を開きます。初回の動画読み込み時に同じ配信元からFFmpeg WebAssemblyを読み込みます。ネイティブFFmpegやRustの起動は不要です。

静的配信用の成果物は `npm run web:build` で `dist-web/` に生成します。確認は `npm run web:preview`。`file://` で直接開かず、HTTP/HTTPSで配信してください。公開版は https://excel-chunchun.sakura.ne.jp/test/chulip-video/ です。

## 操作

1. 「動画を開く」で動画を選ぶか、画面へドロップします。MKV（拡張子の大文字・小文字、MIME未設定を含む）も選択・ドロップできます。
2. 再生・シーク・速度・区間/ループを調整します。「開始秒」「終了秒」または現在位置からの設定で出力範囲を指定します。
3. 枠のドラッグ・8方向のハンドル・座標/寸法入力でクロップします。比率、座標/寸法のロック、Undo/Redo、プリセットを利用できます。
4. ポインターや操作字幕を付ける場合は「操作TSVを開く」で対応ログを選びます。5列の旧形式、6列の現行形式を読み込めます。TSVの座標は動画のピクセル座標です。
5. 「現在PNG保存」「表示内容をCOPY」「PNG連番保存」「MP4 動画保存」「GIF アニメ保存」を使用します。PNG連番はZIP、動画とZIPは生成後の「ダウンロード」から保存します。
6. 保存ボタンで再生・クロップ・プリセット等をブラウザに保存します。同じ名前・サイズ・更新日時の動画を再選択すると編集設定を復元します。動画そのものとTSVは保存しません。

枠外選択は出力時に黒で埋めます。MP4はH.264/AACで出力し、クロップが奇数寸法なら右/下へ最大1px追加します。GIFは15FPS、PNG連番は元動画FPS。字幕はクロップ後の映像下部に表示し、ポインターは元動画の位置に合わせます。

字幕の文字サイズは出力時も指定値を維持します。小さいクロップでは複数段の字幕が画面に収まらないことがあるため、「詳細設定」で文字サイズや最大表示数を小さくしてください。

区間プレビューの折り返しはブラウザの再生イベント周期に従うため、終端を数分の1秒越えてから戻る場合があります。書き出し範囲は指定した開始・終了位置で処理します。

COPYはブラウザのクリップボード権限・対応に依存します。利用できない場合も「現在PNG保存」で同じ合成画像を保存できます。

## 試作上限

- 入力: 固定の容量制限なし。読み取り専用ファイル参照により、元動画全体のメモリーへのコピーを避けます。処理可能な大きさは端末・ブラウザのメモリー等に依存します。
- 単一出力: 512MiBまで。
- 動画・出力・黒埋め中間画像の各寸法: 8192pxまで。
- PNG連番: 1000枚かつRGBA展開画素合計512MiBまで。区間を短くすると使用量を抑えられます。
- TSV: 20MiBまで。
- 保存リンク: 最新の最大3件、合計512MiBまで。古いリンクは解放するため、必要な出力は都度保存してください。

上限内でも端末の空きメモリーによって処理できない場合があります。ブラウザで再生できない形式でもFFmpegで変換できる場合があります。MOV・MKV・HEVCは再生用MP4を端末内で自動生成します。元動画を使って書き出すため、再生用の縮小は保存する動画の解像度に影響しません。元画面で次版扱いの往復再生・PNG選別は追加していません。

## 検証

```powershell
npm run test:web
npm run web:build
npm run build
```

実動画の検証結果・環境と未確認範囲は [版別実装報告](../dev/history/v0.3.0/v0.3.0-imp.md) を参照してください。

ブラウザの統合検証は、Web版を1421番ポートで起動した状態で `node scripts/browser.test.mjs` を実行します。実行環境にはPlaywrightとChromium、および検証素材の生成・出力検査に使うネイティブFFmpegが必要です。FFmpegの場所は `CHULIP_TEST_FFMPEG` で指定するかPATHに登録します。PlaywrightはNodeから解決できる場所へ用意してください。製品の動作にはこれらの検証用ツールは不要です。

検証素材・ダウンロード・結果JSON・スクリーンショットは `dev/history/v0.3.0/logs/web-browser-test/` に保存します。`CHULIP_WEB_URL` で検証先、`CHULIP_RECORD_VIDEO=1` で補助的なPlaywright動画記録を指定できます。実在する利用者の動画をテスト素材にする必要はありません。

- `@ffmpeg/ffmpeg` 0.12.15、`@ffmpeg/core` 0.12.10: https://github.com/ffmpegwasm/ffmpeg.wasm

- Noto Sans JP: [取得元・ハッシュ](../public/vendor/fonts/README.md)、[OFL](../public/vendor/fonts/OFL.txt)

FFmpeg coreの配布ライセンスはGPL-2.0-or-laterです。依存バージョンはpackage-lock.jsonで固定しています。

## PC・スマートフォンの操作

動画、再生ボタン、タイムラインは常に表示されます。「時間」「切り抜き」「字幕」「画像保存」「動画保存」のタブで操作を切り替えてください。タイムラインは指でなぞると再生位置が移動します。ドラッグを始めると再生は一時停止します。画面が小さい場合やキーボード表示中は、下の操作領域内をスクロールできます。
